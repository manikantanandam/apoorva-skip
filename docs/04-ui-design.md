# 04 — UI Design

All screens are rendered as PNGs in [`/designs`](../designs/README.md). Each image shows light (left) and dark (right). They are generated by `python3 designs/_src/generate.py` from one-line screen specs, so editing a design means changing one line and re-running the script.

## 1. Theme system

### Vertical themes (accent + optional canvas tint)

| Theme | Accent light | Accent dark | Canvas tint |
|-------|--------------|-------------|-------------|
| Apoorva Indigo (brand / admin) | #4F46E5 | #A5B4FC | — |

Derived: `soft` = accent at 13% (chips, avatars, notes). `on` = text on accent.

### Type, space, shape
- System font (SF Pro / Roboto). Title 22/700, body 13.5–14, caption 11.5, KPI 19/700. Dynamic Type supported.
- Spacing 4/8/10/12/16. Radius 12 (inputs), 16 (cards), 46 (device). Touch targets ≥ 44 pt.
- Amounts in en-IN grouping (`₹2,84,200`) with tabular figures.

### Theme resolution (first match wins)
1. **Org lock**: if the admin locked the theme, use the org/store accent. The user can still pick Light/Dark/System.
2. **User preference**: accent + mode chosen in Settings → Appearance.
3. **Store theme**: set by the admin per store.
4. **Org theme**.
5. **Vertical default**.

Implementation: `ThemeStore` (`@Observable`) in `ApoorvaUI` exposes resolved tokens through the SwiftUI environment. Changes apply instantly with no restart (target < 100 ms). On Android, Skip maps the same tokens to the Compose `MaterialTheme`.

## 4. Component kit (build once in SwiftUI)
AppBar, SearchField, Chips, Segmented, KPI tile (first tile highlighted), ListRow (avatar, title, subtitle, value, status badge), ItemTile (image, qty badge), CartBar (floating, above tabs), BottomTabs (centre action), Toggle row (with lock state), Keypad, Note (info), Chart card (bars, line, split bar), Permission matrix, Time slot.

## 5. Accessibility
- All text/background pairs ≥ 4.5:1. Accent-on-surface is checked per theme.
- Status always uses text plus colour (Paid/Due/Low), never colour alone.
- Icon-only buttons have labels. Large-text toggle in Appearance.
